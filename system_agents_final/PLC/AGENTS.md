# PLC/AGENTS.md

## 역할
PLC는 실제 자동화 설비 제어, 상태 연동, 경고/정지 등 제어 영역을 담당한다.

현재 PLC는 프로젝트의 주요 기능으로 유지한다.

Cycle의 전진/후진 판별 주 신호는 PLC가 아니라 HC-SR04 3개이다.

기본 연동:

```text
Raspberry Pi 5
↔ Data worX
↔ PLC
```

## 보호 규칙
- PLC 프로그램/레더/제어 주소를 사용자 승인 없이 변경하지 않는다.
- ML 결과를 PLC에서 다시 AI 판별하지 않는다.
- Sensor의 Cycle 판별 역할을 PLC로 되돌리지 않는다.
- 안전 관련 정지/경고 동작은 실제 설비 조건 확인 없이 임의 구현하지 않는다.
- 새 파일/폴더는 사용자 승인 후 생성

## 커밋 / PR
`<type>(plc): <변경 내용>`

Data worX를 통해 필요한 상태/제어 정보가 연결되고 기존 설비 제어와 충돌하지 않아야 완료다.
